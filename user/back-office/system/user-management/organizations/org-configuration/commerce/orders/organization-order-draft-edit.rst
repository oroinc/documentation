Configure Order Draft Edit Mode Settings per Organization
=========================================================

.. note:: The Order Draft Edit Mode feature is available as of OroCommerce version 6.1.9 and can be enabled :ref:`globally <system-configuration-orders-draft-edit-mode>`, per organization, and :ref:`per website <configuration--commerce--orders-draft-edit-mode--website>`.

To enable this feature per organization:

1. Navigate to **System > User Management > Organizations** in the main menu.
2. For the necessary organization, hover over the |IcMore| **More Options** menu at the end of the row and click |IcConfig| to start editing the configuration.
3. Select **Commerce > Orders > Order Draft Edit Mode** in the menu to the left.

.. note:: For faster navigation between the configuration menu sections, use :ref:`Quick Search <user-guide--system-configuration--quick-search>`.

.. image:: /user/img/system/config_commerce/order/order-draft-edit-org.png
   :alt: Order Draft Edit Mode configuration settings per organization

4. In the **Order Draft Edit Mode** section:

   a) Clear the **Use System** checkbox to adjust the settings per organization.
   b) Select the checkbox next to **Enable Order Draft Edit Mode** to enable the feature.
   c) Once enabled, the order edit page uses draft-based editing behavior for all order updates. For more details on the order draft editing behavior, please refer to the :ref:`related article <system-configuration-orders-draft-edit-mode>`

5. Click **Save Settings**.
