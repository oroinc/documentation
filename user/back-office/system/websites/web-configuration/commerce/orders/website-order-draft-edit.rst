Configure Order Draft Edit Mode Settings per Website
====================================================

.. note:: The Order Draft Edit Mode feature is available as of OroCommerce version 6.1.9 and can be enabled :ref:`globally <system-configuration-orders-draft-edit-mode>`, :ref:`per organization <configuration--commerce--orders-draft-edit-mode--org>`, and per website.

To enable this feature per website:

1. Navigate to **System > Websites** in the main menu.
2. For the necessary website, hover over the |IcMore| **More Options** menu to the right of the necessary website and click |IcConfig| to start editing the configuration.
3. Select **Commerce > Orders > Order Draft Edit Mode** in the menu to the left.

.. note:: For faster navigation between the configuration menu sections, use :ref:`Quick Search <user-guide--system-configuration--quick-search>`.

.. image:: /user/img/system/config_commerce/order/order-draft-edit-website.png
   :alt: Order Draft Edit Mode configuration settings per website

4. In the **Order Draft Edit Mode** section:

   a) Clear the **Use Organization** checkbox to adjust the settings per specific website.
   b) Select the checkbox next to **Enable Order Draft Edit Mode** to enable the feature.
   c) Once enabled, the order edit page uses draft-based editing behavior for all order updates. For more details on the order draft editing behavior, please refer to the :ref:`related article <system-configuration-orders-draft-edit-mode>`

5. Click **Save Settings**.
